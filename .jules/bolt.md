## 2023-11-11 - [Unnecessary array mapping and slicing in touch events]
**Learning:** Found an unnecessary double mapping of `touches` array in touch event dispatchers across multiple platform implementations. `e.touches.map(touch => new Touch(touch))` is done twice, once for `touches` and once for `targetTouches`. Additionally, an unnecessary `Array.prototype.slice.call` is being used, when we could just use the mapped array or `Array.prototype.slice()` on the mapped array directly, though in this case `targetTouches` should just be an array of `Touch` objects. Reusing the mapped `touches` array provides a significant performance boost during high-frequency events like touchmove.
**Action:** When mapping arrays to create new objects, check if the same array needs to be assigned to multiple properties. Assign the mapped array to a variable and reuse it.
